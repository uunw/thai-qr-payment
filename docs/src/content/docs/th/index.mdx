## จุดเด่นของไลบรารี

ไลบรารี Thai QR อื่นบน npm ส่วนใหญ่ wrap แพ็กเกจ [`qrcode`](https://www.npmjs.com/package/qrcode) ทำให้ผูกติดกับ API เฉพาะ Node หรือมีขนาด blob สูงถึง 30 KB ไลบรารีนี้พัฒนาด้วย TypeScript ตั้งแต่ต้นจนจบ:

<CardGrid>
  <Card title="ไม่มี runtime dependency" icon="seti:typescript">
    ไม่ต้องอาศัย `qrcode`, `canvas` หรือ `crc16` คำสั่ง `npm install thai-qr-payment` ดึงมาเพียง
    **tarball เดียว**
  </Card>
  <Card title="รองรับทุก runtime" icon="open-book">
    Browsers, Node ≥ 22, Bun, Deno, Cloudflare Workers, Vercel Edge — bundle เดียวกัน
  </Card>
  <Card title="ขนาดเล็ก" icon="rocket">
    Bundle เต็ม 13.6 KB brotli, sub-path เฉพาะ payload 3 KB
  </Card>
  <Card title="ครอบคลุมตามมาตรฐาน" icon="approve-check">
    EMVCo MPM 1.1 + Bank of Thailand supplement, ISO/IEC 18004 QR Model 2 พร้อม vitest 337 รายการ
    สำหรับแพ็กเกจ payload เพียงอย่างเดียว
  </Card>
  <Card title="พร้อมใช้งานกับ React" icon="seti:react">
    `<ThaiQRPayment />` และ `<ThaiQRPaymentMatrix />` รองรับ SSR โดยกำหนด React เป็น peer dependency
  </Card>
  <Card title="พร้อม CLI ในตัว" icon="seti:shell">
    `npx thai-qr-payment 0812345678 --amount 50 -o qr.svg`
  </Card>
  <Card title="ครอบคลุมมากกว่า PromptPay" icon="puzzle">
    PromptPay แบบบัญชีธนาคาร, OTA credit transfer, [TrueMoney Wallet QR](/guide/payload/), [VAT
    TQRC](/reference/spec/#vat-tqrc-template-under-tag-80), bill payment ข้ามประเทศ, [Slip Verify
    Mini-QR](/guide/slip-verify/) และ [BOT 1D barcode](/guide/barcode/)
  </Card>
</CardGrid>
