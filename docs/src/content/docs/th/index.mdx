## ทำไมต้องมีไลบรารีนี้

ไลบรารี Thai QR ตัวอื่น ๆ บน npm ล้วน wrap แพ็กเกจ [`qrcode`](https://www.npmjs.com/package/qrcode) มัดคุณไว้กับ API เฉพาะ Node หรือไม่ก็ส่งมาเป็น blob ขนาด 30 KB ไลบรารีนี้เขียนด้วย TypeScript เองตั้งแต่ต้นจนจบ:

<CardGrid>
  <Card title="ไม่มี runtime deps" icon="seti:typescript">
    ไม่มี `qrcode` ไม่มี `canvas` ไม่มี `crc16` `npm install thai-qr-payment` ดึงมาเพียง **tarball
    เดียว**
  </Card>
  <Card title="ใช้ได้ทุกที่" icon="open-book">

  </Card>
  <Card title="ขนาดเล็ก" icon="rocket">

  </Card>
  <Card title="ตรงตามสเปก" icon="approve-check">
